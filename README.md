# Building an Operating System

## Languages

Documentation is available in English and Italian.

English is the canonical language for source code, comments, identifiers,
commit messages, issues, and technical terminology. Italian documentation
is maintained as a corresponding translation.

## Lingue

La documentazione è disponibile in inglese e italiano.

L’inglese è la lingua canonica per codice sorgente, commenti, identificatori,
messaggi di commit, issue e terminologia tecnica. La documentazione italiana
viene mantenuta come traduzione corrispondente.
